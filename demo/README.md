# Demonstration materials

No live 0.7.0 demonstration is included. Use a disposable app/profile for a future authorized example. A separate recorder requires separate personal GNOME consent and is not started automatically. Review full frames before sharing any recording. No custom controls or pointer effects are part of the recorder.

Live examples must first obtain desktop_start consent and inspect the fresh image, then launch apps through the observed GUI. Never prepare a live scene by shell/subprocess/xdg-open/wmctrl/D-Bus app launch or focus before consent. Manual fixtures are isolated test aids, not live preconsent windows. See examples/consent_first.py.
