# Installation

Use install.sh --check before installation. install.sh resolves the local MCP declaration, copies the optional indicator-only extension and installs the local marketplace plugin. The app must refresh its MCP catalog. The new indicator UUID is desktop-indicator@local.codex. GNOME may need a manual logout/login to discover it; no session restart is automated. The indicator has no shortcuts or reactive controls. Core consent/input tools work independently and report label unavailability explicitly.
