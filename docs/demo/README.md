# Look, ChatGPT is drawing a bear

[Watch the video](look-chatgpt-draws-a-bear.webm)

The 4-minute-39-second silent recording shows Firefox opening Kleki, followed by GUI brush strokes creating a colored teddy bear with ears, eyes, muzzle, smile, belly, paw pads, seam details and a red scarf. The final painting uses about 35 brush strokes. No image, SVG, script-generated canvas or clipboard artwork is imported.

The edit combines website-opening footage with a later painting session, labels the resumed session, removes approval/setup waits, and hides unrelated browser tab titles. Drawing proceeds at recorded speed. The linked poster is a crop from a clean recorded frame, not a web-app PNG export. The original full recordings remain local.

Recorded on the tested GNOME host using plugin 0.8.16 and helper 0.8.6. Scoped success does not establish universal device/app coverage. The session ended with confirmed portal closure, zero held input and no cleanup warning. A later optional background batch was refused before input; it does not appear in this demo.

The repository remains private. This is an independent project, not an official OpenAI product.
