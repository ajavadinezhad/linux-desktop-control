# Look, ChatGPT is drawing a bear

https://github.com/user-attachments/assets/84610a30-2aff-4836-b048-608dfcd90eef

The 4:39 silent demo shows Firefox opening Kleki and a bear painted with about 35 real GUI brush strokes: ears, face, belly, paws and a red scarf. No imported artwork or scripted canvas is used.

Setup waits are removed, the resumed painting session is labeled, and unrelated tab titles are hidden. Drawing runs at recorded speed. The video is hosted as a GitHub attachment for inline playback; original recordings and the poster frame remain local.

Recorded with plugin 0.8.16/helper 0.8.6 on the tested GNOME host. This independent integration is not an official OpenAI product. See [release status](../RELEASE_STATUS.md) for acceptance limits.
