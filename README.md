# Linux Desktop Control

**Preview — currently supports GNOME Shell 51 on Wayland only.** Other platforms are planned; they are not supported yet.

ChatGPT, working through your Linux desktop. Open apps, create slides, and paint using the same visible controls you use.

## Look, ChatGPT is drawing a bear

https://github.com/user-attachments/assets/d19dd61d-1065-4b88-8160-1ac383e79383

**4 minutes 20 seconds of real GUI painting.** Drawing a bear with a face, paws, and a red scarf in Kleki. No imported artwork or playback speed-up. Private setup is removed, desktop edges are cropped, and download details are covered.

## What it can do

- Work in visible GNOME Wayland apps through keyboard and mouse input.
- Create and save documents, presentations, and browser artwork.
- Fit and move windows onto the shared monitor in supported two-monitor layouts.
- Pause for covered physical mouse movement and return after quiet, when enabled and verified.

## You stay in control

Sharing requires your GNOME approval. Foreground, monitor, and pointer checks guard input. Stop and sharing revocation end control. Optional native takeover monitoring requires a separately approved system helper.

**Supervised beta.** Tested on the current setup; broader device and app coverage remains unfinished. Independent integration, not an official OpenAI product.
